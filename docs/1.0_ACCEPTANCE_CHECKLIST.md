## Accuracy boundary

The pilot model remains `illustrative_proxy_not_cad`. The current 24 fin meshes, fan blade shapes, PCB outline, internal component positions and shroud contour are proxies. The published 201.8 mm length is nominal and is not a hard upper bound for all exterior geometry. LanOC reports an unquantified shroud overhang.

The current power and cooling layers are qualitative educational explanations. They are not CFD, thermal FEA, SPICE, electrical net tracing or a service procedure. Assembly steps are intentionally not authored until the full teardown sequence is reviewed.

## 1.0 release rule

Do not tag 1.0 while any unchecked product gate remains. The project can publish an educational 1.0 with clearly labelled proxy geometry only if the intended scope is explicitly educational and no repair/manufacturing accuracy is implied. A precision engineering release requires measured geometry, exact PCB revision identification and separate engineering validation.
