# Local model files

The generated Blender/GLB artifacts are intentionally not committed by default.

To load the pilot model automatically, copy the locally generated file to:

`public/models/rtx3060_xc_black_blockout_v04.glb`

Alternatively, start the viewer and use **Open GLB** to select any compatible GLB file. The app falls back to an explicitly illustrative demo scene when no bundled model exists.
