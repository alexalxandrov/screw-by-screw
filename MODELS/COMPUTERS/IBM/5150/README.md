# IBM Personal Computer 5150 — system unit (1981)

**Model ID:** `computer.ibm.5150.1981`  
**Package:** `0.1.0-draft`  
**Geometry status:** `illustrative_proxy_not_cad`

This is the second reference model in Screw by Screw. Scope is the **system unit only**: no monitor, keyboard, printer, external cassette recorder, or optional expansion cards.

## Baseline

The modeled baseline is the August 1981 launch configuration: 16 KB RAM, no installed diskette drive, two empty drive positions, five unpopulated expansion sockets, and an unpopulated optional 8087 socket. The first-edition technical reference and service manuals define the hardware family; later 5150 board revisions and the IBM PC/XT 5160 are excluded.

The package currently contains 71 canonical semantic components, 100 typed relationships, 20 source-linked claims, five functional layers, 12 bilingual learning questions, five partial FRU service procedures, and two explanatory animation clips.

## Evidence limits

The 8.5 × 11 inch system-board outline, 4.77 MHz CPU clock, 14.31818 MHz reference crystal, and 63.5 W / 120 Vac PSU specification are source-backed. The case envelope and most component placement are visual proxies. Board hole pattern, exact component coordinates, individual DRAM/ROM population, fastener dimensions, thread, torque, and chassis sheet-metal geometry are not asserted as measured facts.

The five service operations are source-backed partial procedures, not a universal screw-by-screw teardown order. The PSU is represented as a sealed FRU. Disconnect mains before opening the case; do not open or probe the PSU.
