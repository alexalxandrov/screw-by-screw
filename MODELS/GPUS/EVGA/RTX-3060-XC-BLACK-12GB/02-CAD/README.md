# 02 — CAD source files

Reserved for original STEP/STP, IGES, native CAD, and imported assembly files.

**Current status:** no verified exact-SKU native CAD assembly has been located.

Before adding a file, record its source, exact model/revision applicability, license, permission to modify/redistribute, units, coordinate system, and hash. Do not substitute a generic RTX 3060 or XC Gaming CAD assembly without marking and proving equivalence.
